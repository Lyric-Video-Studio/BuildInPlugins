Automatic1111 TxtToImg
Capabilities - Create images from text prompts with locally installed Stable Diffusion or SDXL checkpoints.
Workflow - Automatic1111 text-to-image: generate images using the currently selected local checkpoint, model and LoRA; the checkpoint list is dynamic and cannot be enumerated from a static plugin catalog.
Current - Uses the checkpoints and models installed in the connected Automatic1111 instance.
Current - Search terms: Stable Diffusion, SDXL, text-to-image, txt2img, checkpoint.
